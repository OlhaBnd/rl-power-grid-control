## Опис

Програмна система керування топологією енергомережі IEEE 14-bus
на основі алгоритму глибокого навчання з підкріпленням PPO
(Proximal Policy Optimization). Система здатна запобігати блекаутам
при раптових відключеннях вузлів генерації шляхом автоматичного
перерозподілу топології мережі в реальному часі.

## Вимоги

- Python 3.10 або вище
- pip

## Встановлення

Клонувати репозиторій та встановити залежності:

```bash
git clone <url репозиторію>
cd diplom
pip install -r requirements.txt
```

## Використання

### Навчання агента

```bash
python src/train.py
```

Навчена модель зберігається у директорію `models/`.  
Час навчання: приблизно 30 хвилин на CPU.  
Логи навчання зберігаються у `tensorboard_logs/`.

### Перегляд графіків навчання

```bash
tensorboard --logdir tensorboard_logs/
```

### Порівняльне тестування

```bash
python src/evaluate.py
```

Результати зберігаються у `outputs/benchmark_results.json`.

### Веб-застосунок

```bash
streamlit run app.py
```

Застосунок відкривається у браузері за адресою http://localhost:8501.

### Консольне демо

```bash
python src/demo.py
```

## Структура проєкту

```
diplom/
├── src/
│   ├── env_setup.py      # Налаштування середовища Grid2Op
│   ├── reward.py         # Власна функція винагороди CustomReward
│   ├── train.py          # Навчання PPO агента
│   ├── evaluate.py       # Порівняльне тестування методів
│   ├── topology.py       # Візуалізація топології мережі
│   ├── visualize.py      # Графіки процесу навчання
│   ├── animation.py      # Анімація порівняння агентів
│   ├── demo.py           # Консольна демонстрація
│   └── find_hard.py      # Пошук складних сценаріїв
├── models/               # Збережені навчені моделі
│   ├── ppo_grid2op.zip
│   ├── ppo_grid2op_v2.zip
│   └── ppo_grid2op_v3.zip
├── outputs/              # Результати тестування та візуалізації
├── tensorboard_logs/     # Логи навчання

├── test_reward.py        # Unit-тести функції винагороди
├── requirements.txt      # Залежності проєкту
└── README.md
```
